# Spec Summary (Lite)

Offer to file every photo or document the assistant sees, by default. In the app's chat, each attachment gets a
filing card that the `offer_to_file` tool refines with a category and linked record, and File uploads the
original from the browser. Over MCP, the same tool returns a cambelt.app link that opens the upload sheet
pre-filled, because an MCP client cannot hand over the file. Unplaceable photos default to Car photo.
